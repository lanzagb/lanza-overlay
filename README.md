# LANZA – Project Claude V2 overlay

The code for the "Project Claude V2" StreamElements custom widget (twitch.tv/lanza), served by GitHub Pages:

- `widget.css` – all the styling
- `widget.js` – all the behaviour

The StreamElements widget itself only holds a tiny loader (HTML + JS tabs) and the Fields (settings).
No tokens or keys live in this repository – they stay in the StreamElements fields.
